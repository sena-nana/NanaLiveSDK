# 快速开始

本站是 NanaLive SDK 与插件开发文档。正文会随协议稳定后陆续补充。

1. 读本站了解流程
2. 以仓库 [`SDK/js`](https://github.com/sena-nana/NanaLiveSDK/tree/main/SDK/js)（`@nanalive/sdk`）为依赖
3. 对照 [`Plugins/streamdeck/`](https://github.com/sena-nana/NanaLiveSDK/tree/main/Plugins/streamdeck) 官方示例

第三方插件请放在自己的仓库并打上 `nanalive` topic，不要提交到本仓库。

本地预览：`cd Docs && npm install && npm run docs:dev`。部署见 [部署文档站](/guide/deploy)。

# Docs

本目录是 NanaLive SDK 与插件开发的文档入口。

## 本目录放什么

- 快速开始
- 插件开发指南
- API 参考索引

正文将随 SDK 落地陆续补充。当前请先阅读仓库根目录 [README](../README.md) 了解整体结构。

## 本目录不放什么

- SDK 实现、协议定义或语言绑定（见 [`../SDK`](../SDK)）
- 可运行的官方插件示例（见 [`../Plugins`](../Plugins)）
- 第三方插件源码

## 第三方插件

第三方插件不收录于本仓库。请在作者自己的仓库中发布，并为该仓库打上 `nanalive` 标签。

## 建议阅读顺序

1. 本目录的快速开始与插件开发指南（待补充）
2. [`../SDK`](../SDK) 中的 SDK 与协议
3. [`../Plugins`](../Plugins) 中的官方示例

# 插件市场

列表来自 `registry/plugins.json`。源码在作者仓库，不收录在本仓库。

评分只按赞踩比：`5 × 赞 / (赞 + 踩)`。赞踩写入 giscus Discussion（👍 / 👎），列表用 giscus 推送的元数据在浏览器里算星星，不写回 git。无人投票或尚未建帖显示「暂无评分」。纯比例排序时，1 个赞会排在 99 赞 1 踩前面。

实现优秀程度是另一套徽章（README / Release / CI / 源码等），与口碑无关。`license` 和归档是标签；仓库必须带 `nanalive` topic 才能登记。

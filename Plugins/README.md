# Plugins

本目录只存放 NanaLive 的官方 Plugin 示例。第三方开发者可对照这些示例了解推荐写法与目录组织，但不要把第三方插件提交到本仓库。

## 约定

**一个插件一个子目录**，例如后续可能出现的 `hello-world/`。

每个插件目录应自包含：可独立阅读、构建与运行所需的文件，不把协议规范或 SDK 实现散落到插件内部。

## 本目录放什么

- 官方维护的示例插件源码
- 各示例插件自带的简要说明（插件目录内的 README）

当前尚未收录示例实现；待 SDK 协议稳定后再加入。

## 本目录不放什么

- 插件协议、语言绑定或脚手架模板（见 [`../SDK`](../SDK)）
- 通用开发文档与 API 索引（见 [`../Docs`](../Docs)）
- 第三方插件（请使用自己的仓库，并为仓库打上 `nanalive` 标签）

## 第三方插件

第三方插件应发布在作者自己的仓库中，并为该仓库打上 `nanalive` 标签。本目录与本仓库均不接受第三方插件的 Pull Request。

## 与其他目录的关系

示例插件依赖 [`../SDK`](../SDK) 提供的接口，用法说明以 [`../Docs`](../Docs) 为准。
